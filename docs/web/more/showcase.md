# Showcase

There are no published user showcases listed yet. For now, the repository's
`examples/` directory demonstrates generated functions, methods, templates,
and lambdas, followed by model selection, cache policies, and custom agents.

Start with the small vector-sorting example before the graph and template
examples. The [tutorials](../tutorials/build_the_compiler.md) walk through a
complete program if you prefer to learn by building something.
